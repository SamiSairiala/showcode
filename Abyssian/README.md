# Abyssian – Code Samples (Unity / C#)

Selected scripts from my work on **Abyssian** (2.5D JRPG) focusing on character/combat-related systems and equipment UI.

## Files
- `CombatCharacter.cs` : Core character representation used by combat/game systems (stats/state hooks)
- `EquipmentMenuController.cs` : Equipment UI controller (menu interactions, slot handling, applying changes)
